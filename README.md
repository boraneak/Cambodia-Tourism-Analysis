# Cambodia Tourism Analysis

## Business Task

Cambodia tourism industry was hit hard by COVID-19 border closures. This project looks at how international tourist arrivals have recovered since the 2019 pre-pandamic peak, which countries are driving that recovery, and what seasonal patterns hotels and tour operators should plan around.

**Stackholders** Minstry of Tourism, hotels and tour operators, investors in Cambodia's tourism sector.

**Key questions** 

1. What's the overall recovery trend from 2019 to now — total arrivals, and what
   % of the 2019 baseline are we back to?
2. Which countries are the top source markets, and how has that ranking changed
   since 2019?
3. Is there a seasonal pattern — which months see the most visitors?
4. How has the entry mode (air vs. land vs. water) shifted over time?

## Approach

This project follows the six-phases data analysis process (Ask -> Prepare -> Process -> Analyse -> Share -> Act), the same structures taught in the Google Data Analytics Professional Certificates.
