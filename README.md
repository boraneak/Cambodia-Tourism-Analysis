# Cambodia Tourism Analysis

## Business Task

Cambodia tourism industry was hit hard by COVID-19 border closures. This project looks at how international tourist arrivals have recovered since the 2019 pre-pandamic peak, which countries are driving that recovery, and what seasonal patterns hotels and tour operators should plan around.

**Stackholders** Minstry of Tourism, hotels and tour operators, investors in Cambodia's tourism sector.

**Key questions:**

1. **Recovery:** How many international visitor arrivals were recorded in each
   calendar year from 2019 through the latest complete year in the dataset, and
   what percentage of the 2019 total did each year represent?
2. **Source markets:** Which five countries generated the most visitor arrivals
   in 2019 and in the latest complete year, and how did each country's arrival
   count, share, and ranking change between those years?
3. **Seasonality:** From January 2019 through the latest complete year in the
   dataset, which calendar months had the highest and lowest average visitor
   arrivals, based on monthly averages across the available years?
4. **Entry mode:** For each calendar year from 2019 through the latest complete
   year in the dataset, how many visitors entered by air, land, and water, and
   how did each mode's share of total arrivals change compared with 2019?

## Approach

This project follows the six-phases data analysis process (Ask -> Prepare -> Process -> Analyse -> Share -> Act), the same structures taught in the Google Data Analytics Professional Certificates.
